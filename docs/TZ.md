# Технічне завдання: «Brew & Bean»

Сайт кав'ярні з онлайн-меню (варіант 3).
Автор: Карапутна Тетяна. Версія 1.0.

## 1. Призначення
Сайт дозволяє відвідувачу переглянути актуальне меню кав'ярні, зібрати кошик з автоматичним підрахунком суми, оформити замовлення з вибором часу отримання та зв'язатися із закладом.

## 2. Цільова аудиторія
Мешканці міста 18–45 років: студенти й офісні працівники, які замовляють каву з собою. Основний пристрій — смартфон.

## 3. Карта сторінок
| Сторінка | URL | Призначення |
|---|---|---|
| Головна | `/` | Про заклад, популярні позиції |
| Меню | `/menu` | Список позицій, фільтр, пошук |
| Деталі позиції | `/menu/:id` | Опис, обсяг, ціна, кнопка «Додати» |
| Кошик | `/cart` | Позиції, сума, форма замовлення |
| Контакти | `/contacts` | Адреса, графік, форма зворотного зв'язку |
| 404 | `*` | Сторінка неіснуючої адреси |

## 4. Функціональні вимоги
1. Перегляд списку позицій меню з картками (фото, назва, ціна).
2. Фільтрація за категорією та пошук за назвою.
3. Сторінка деталей позиції з описом, обсягом і ціною.
4. Додавання позиції до кошика, зміна кількості, видалення.
5. **Автоматичний підрахунок суми кошика** (обов'язкова функція варіанта).
6. Оформлення замовлення через форму з валідацією.
7. Форма зворотного зв'язку з валідацією на клієнті та сервері.
8. Збереження кошика між відвідуваннями (localStorage).
9. Перемикач світлої та темної теми.
10. Додавання й видалення позицій меню через API (CRUD).

## 5. Нефункціональні вимоги
- Адаптивність: 360, 768, 1280 px (mobile-first).
- Lighthouse (mobile) ≥ 90 у всіх категоріях.
- Відповідність WCAG 2.1 AA (контраст ≥ 4,5:1, навігація з клавіатури).
- SEO: унікальні `title` і `description`, `robots.txt`, `sitemap.xml`, JSON-LD.
- Валідна розмітка (W3C Nu Html Checker без помилок).
- Підтримка PWA (manifest, service worker, офлайн-сторінка).

## 6. Стек технологій
- Клієнт: HTML5, CSS3, JavaScript (ES-модулі), React + Vite, React Router.
- Сервер: Node.js, Express, JSON-файл як сховище.
- Тести: Vitest, React Testing Library, Lighthouse, axe DevTools.
- Інструменти: Git/GitHub, Figma, Postman.
- Деплой: Vercel/Netlify (клієнт), Render/Railway (сервер).

## 7. Структура даних
Сутність «Позиція меню»:

| Поле | Тип | Опис |
|---|---|---|
| id | number | Ідентифікатор |
| name | string | Назва |
| category | string | coffee, tea, dessert, food |
| description | string | Опис |
| price | number | Ціна, грн |
| volume | string | Обсяг або вага |
| image | string | Шлях до зображення |
| available | boolean | Наявність |

## 8. API (план)
| Метод | URL | Коди |
|---|---|---|
| GET | `/api/items` | 200 |
| GET | `/api/items/:id` | 200, 404 |
| POST | `/api/items` | 201, 400 |
| PUT | `/api/items/:id` | 200, 400, 404 |
| DELETE | `/api/items/:id` | 204, 404 |
| POST | `/api/contact` | 201, 400 |
