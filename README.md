# Тепла кухня — навчальний інтернет-магазин

Курсова робота з дисципліни «WEB-технології та WEB-дизайн», тема 27: «Розробка інтернет-магазину з кошиком покупця та фільтрацією товарів».

## Запуск
Відкрийте `index.html` у браузері. Збірка та сервер не потрібні.

## Структура
- `index.html` — розмітка сторінки, фільтри, діалоги кошика й оформлення
- `css/styles.css` — стилі та адаптивність
- `js/products.js` — дані товарів
- `js/app.js` — фільтрація, кошик (localStorage), валідація форми

## Публікація
Після завантаження в репозиторій увімкніть GitHub Pages: Settings → Pages → Branch: main, папка /(root).

# Brew & Bean ☕

Навчальний вебпроєкт кав'ярні, створений за допомогою React.

## Опис проєкту

Brew & Bean — вебсайт кав'ярні, де користувачі можуть переглядати меню, додавати товари до кошика та оформлювати замовлення.

## Використані технології

- React
- JavaScript
- Vite
- React Router
- CSS
- LocalStorage

## Основні можливості

- Головна сторінка кав'ярні.
- Каталог товарів.
- Пошук і фільтрація меню.
- Перегляд детальної інформації про товари.
- Додавання товарів до кошика.
- Зміна кількості товарів.
- Оформлення замовлення.
- Збереження історії замовлень.
- Зміна статусу замовлення.
- Фільтрація замовлень за статусом.
- Видалення замовлень.
- Контактна форма.

## Запуск проєкту

1. Встановити Node.js.
2. Відкрити термінал у папці `client`.
3. Встановити залежності:

   `npm install`

4. Запустити сайт:

   `npm run dev`

5. Відкрити адресу `http://localhost:5173/`.

## Перевірка збірки

Для перевірки проєкту виконайте:

`npm run build`

## Зберігання даних

Кошик та історія замовлень зберігаються в LocalStorage браузера. Серверна база даних у проєкті поки не використовується.
