# Тепла кухня — навчальний інтернет-магазин

Курсова робота з дисципліни «WEB-технології та WEB-дизайн», тема 27: «Розробка інтернет-магазину з кошиком покупця та фільтрацією товарів».

## Запуск
Відкрийте `index.html` у браузері. Збірка та сервер не потрібні.

## Структура
- `index.html` — розмітка сторінки, фільтри, діалоги кошика й оформлення
- `css/styles.css` — стилі та адаптивність
- `js/products.js` — дані товарів
- `js/app.js` — фільтрація, кошик (localStorage), валідація форми

## Публікація
Після завантаження в репозиторій увімкніть GitHub Pages: Settings → Pages → Branch: main, папка /(root).
